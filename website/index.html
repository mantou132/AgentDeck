Up and running in a minute

A free agent is built in, so you can try it without an account or an API key.

Install the daemon

On the computer where your agents run. macOS, Linux and Windows.

npm install -g agentdeckd
brew install mantou132/tap/agentdeckd

Start it

It runs in the background and starts with your computer. No open ports, no VPN.

agentdeckd start

Scan and go

Scan the QR code it prints with the AgentDeck app, then pick an agent. Choose Free to start right away.

Your code stays on your machine

Phone and computer pair with a secret ID from the QR code and derive encryption keys from it. The relay only ever sees ciphertext, and you can host it yourself. No accounts, no analytics, no tracking.
